# SmartSupport – AI-Powered Customer Support System

## 📌 Overview

SmartSupport is an AI-powered customer support system that helps organizations manage customer tickets, analyze complaints, and generate intelligent responses using Artificial Intelligence.

## 🚀 Features

* Customer ticket management
* AI-based ticket analysis
* Automatic ticket classification
* AI-generated responses
* Knowledge-base search
* Semantic search using vector embeddings
* RAG-based response generation
* Customer support dashboard
